## Questions for the decider

Past tense, about his own use. Each one is an account question (n = 1).

- Q-U1 · When you played RENT slice 1 for three minutes, what did you notice in the first rounds, and why did the rounds end so fast? · decides: whether short rounds come from the game rule or from tuning, and so how the engine's bench counts pure-play time.
- Q-U2 · When you said RENT was "good" but not "exciting", what did you expect to happen that did not? · decides: what "exciting" means for effects in C, since it is the restyle's pass line.
- Q-U3 · When you read "not the real physics for the weight and material", which moment broke it most: the overhang, the landing or the collapse? · decides: which physics event to build first on the engine, and which Python event to expose first.
- Q-U4 · When the AI built slices 2 and 3 while you were away, what would you have wanted it to wait for? · decides: whether the engine's work waits for a feel check before the next slice, and so the size of a slice.
- Q-U5 · When a new build went on the board, how long did you wait, and how often did it not run (dark board, dropped port, old files)? · decides: whether deploy time and failure matter to the engine's design (a flash for each C change versus a copy of Python files).
- Q-U6 · When you wanted another game, how did you pick it with D14, and how many presses did it take? · decides: whether the engine needs a menu or a picker, or whether a cycle is enough for eleven games.
- Q-U7 · When a game ended, did you ever press and nothing happened (the 900 ms lock), and did it annoy you? · decides: whether the engine's shell keeps the lock, shortens it, or makes it a setting.
- Q-U8 · When you gave a verdict such as "stucky" or "stepped", how did you know it had changed after the next build? · decides: whether the engine should show a number (fps, worst gap) in play, or whether his eyes are the gauge.
- Q-U9 · When you described a physical rule to the AI (steel does not snap, tips at the centre of weight), how long did you take to write it, and would you write the next rule in the same way? · decides: whether rules are given as words that the AI turns into an engine call, or whether the engine needs a data file you edit.
- Q-U10 · When your sister has played one of the ten games, which one, and what did she do (stop, get stuck, ask)? · decides: the "simple version" settings of the area-capture game, and whether she is a user at all (today n = 0).
- Q-U11 · When you checked a physical event in a game (a landing, a tip-off), what did you want to see besides the motion (dust, a clang, a number)? · decides: which events Python must react to, and so the engine's event list.
- Q-U12 · When you wanted a game to look different (the restyle) and to move differently (RENT), which did you change by words first, and which by asking for a number? · decides: whether feel parameters (weights, speed) are exposed as named settings in the binding.
