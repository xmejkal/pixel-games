## Frame
- Request, verbatim (corrections marked): "I'd also like to build a project to show, I was thinking something with the sound, or just add sound to the games ... do some research and POC for how to best work with sound and maybe also what is all possible with the S3's abilities and to test also doing some C based drivers or libraries for the sound effects ... not reinvent the wheel, reuse, research first, see what other industry standard projects use, what naming, if there are some reusable libraries or some we could extend, or just get inspired by ... how to then best combine it with the existing games ... what should be low level ... compare some simple python version and then have a good architecture so we can just swap it for a more optimized one ... something like some benchmark, like with the graphics ... how would it combine with physics ... the fire effect I would love to add autogenerated realistic sound effects to it ... both a naive micropython implementation, but also the optimized custom sound effects library or even an optimized driver to use the S3's capabilities." (the PO, 2026-11-09, https://github.com/xmejkal/spark/issues/997) <!-- REQUIRED:request -->
